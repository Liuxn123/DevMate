# DevMate 学习接续入口

本目录服务于协助开发 DevMate 的 Agent，维护跨会话接续信息。产品运行时 Agent 位于后端 Java 包，代码职责见 [Agent 开发说明](../文档/Agent开发说明.md)。

## 接续顺序

1. [仓库规则](../AGENTS.md)：范围、授权与实现边界。
2. [当前状态](STATUS.md)：已实现内容、验证证据与下一步。
3. [学习与开发待办](../任务清单.md)：确定本轮切片。
4. [近期交接](HANDOFF.md)：近期变更、限制及历史索引。
5. 按需阅读 [里程碑](MILESTONES.md)、[产品资料](../文档/) 和相关代码；历史问题再查 `history/`。

## 文件职责

| 文件 | 维护内容 |
|---|---|
| `README.md` | 接续导航和本目录约定 |
| `STATUS.md` | 当前事实及验证状态，不保存完整流水账 |
| `MILESTONES.md` | 阶段目标、边界与验收标准 |
| `TASKS.md` | 指向根目录待办的兼容入口 |
| `TASKS-AI.md`、`TASKS-MANUAL.md` | 工作台任务同步表，保留协议、ID 和标记 |
| `HANDOFF.md` | 近期实质变更，引用验证证据和未完成项 |
| `history/YYYY-MM.md` | 历史交接归档，保留原始事实 |

根目录 `任务清单.md` 是学习与开发待办真源；工作台任务表保留其同步用途。不要在本目录另建重复的总任务清单，也不要仅因代码已写就把运行验收标为完成。完整目录约定见 [目录结构](../文档/目录结构.md)。
