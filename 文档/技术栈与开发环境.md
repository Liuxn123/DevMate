## 产品运行边界

- V1 用户项目范围：Windows 上常规 Java / Spring Boot + Maven 项目。
- Node.js 用户项目支持放在 V1.1；DevMate 自己的 Vue 前端仍通过 Node.js 构建。
- 后端默认监听 `127.0.0.1:8080`；前端 Vite 开发服务器监听 `127.0.0.1` 并代理 `/api`。
- 项目运行时优先使用进程级 `JAVA_HOME`、`PATH` 和工具版本配置；默认不修改系统全局环境变量。
- 安装工具、运行项目脚本、修改系统环境或受管项目配置前，必须经过针对该操作的明确审批。
- AI 输出不得作为任意 Shell 命令直接执行；所有变更动作须经过程序定义的类型、参数和权限校验。

## 本机环境记录

本机环境会变化，版本信息应标注观察日期并通过版本查询命令重新确认。2026-10-13 实测：终端 `java -version` 为 JDK 11.0.28；Maven 3.9.4 使用 `E:\learn\java\jdk` 下的 JDK 21.0.3；Node.js 24.19.0、npm 11.17.0。Spring Boot 启动日志与 `/api/health` 响应均显示服务 JVM 为 Java 21.0.3。启动 Maven 时使用了临时 settings 与临时本地仓库，没有更改全局 Maven 设置。

本轮 M0 的 HTTP 观察：`http://127.0.0.1:5173/` 返回 200；`http://127.0.0.1:8080/api/health` 直连及经 `http://127.0.0.1:5173/api/health` 的 Vite 代理都返回 `{"status":"UP","application":"devmate","javaVersion":"21.0.3"}`。浏览器 Network 面板仍需学习者亲自观察并解释。
