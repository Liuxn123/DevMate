# 目录结构与维护约定

项目保留双模块结构，按“代码、产品文档、开发协作、学习记录”分工。中文文档目录沿用现状，固定入口兼容现有 Obsidian 与项目工作台。

```text
P-2026-001-DevMate/
├── AGENTS.md                 # 开发 Agent 的规则入口
├── README.md                 # 仓库入口、运行说明与导航
├── 项目主页.md               # Obsidian 项目入口
├── 任务清单.md               # 学习与开发待办真源
├── agent/                    # 开发协作上下文，非产品运行代码
│   ├── README.md             # 接续顺序与文档职责
│   ├── STATUS.md             # 当前状态、证据、下一步
│   ├── MILESTONES.md         # 阶段目标与验收标准
│   ├── TASKS.md              # 待办导航
│   ├── TASKS-AI.md           # 工作台 AI 任务同步接口
│   ├── TASKS-MANUAL.md       # 工作台手工任务同步接口
│   ├── HANDOFF.md            # 近期交接及历史索引
│   └── history/             # 按月保存的交接历史
├── 文档/                     # 产品定位、需求、架构、路线、原型及开发说明
├── 笔记/                     # 学习过程记录，按需创建，不存放权威需求
├── devmate-server/           # Spring Boot / Maven 后端
│   └── src/main/
│       ├── java/com/devmate/
│       │   ├── agent/        # controller、dto、service、repository、model、tool、trace、exception
│       │   ├── project/      # controller、dto、service、repository、model、exception
│       │   ├── environment/  # controller、service、model
│       │   ├── task/         # controller、dto、model、repository、service：计划、审批、进程与日志
│       │   ├── health/       # controller、dto
│       │   └── common/       # dto、exception：通用 API 错误处理
│       └── resources/
│           ├── application.yml
│           └── db/migration/ # 版本化数据库迁移，提交仓库
└── devmate-web/              # Vue / Vite 前端
    └── src/                 # App.vue、style.css；components/TaskWorkspace.vue 为任务工作区
```

## 新文件放在哪里

| 内容 | 位置 | 维护方式 |
|---|---|---|
| 对开发 Agent 的长期规则 | 根目录 `AGENTS.md` | 只写可复用规则，不写任务流水账 |
| 当前事实、验证限制、下一步 | `agent/STATUS.md` | 更新现状，不重复完整历史 |
| 本次实质变更与验证 | `agent/HANDOFF.md` | 按日期追加，旧月份转入 `history/YYYY-MM.md` 并保留索引 |
| 待办与学习验收 | 根目录 `任务清单.md` | 统一维护，其他入口引用 |
| 工作台任务表 | `agent/TASKS-AI.md`、`agent/TASKS-MANUAL.md` | 遵守文件内同步协议，状态差异以实际验收证据解释 |
| 产品设计与架构决策 | `文档/` | 现行文档互相链接，设计目标不等同于已实现能力 |
| 学习复盘 | `笔记/YYYY-MM-DD-主题.md` | 按需新增，引用代码与观察证据 |
| 产品 Agent 功能 | 后端 `com.devmate.agent` 下的职责子包 | HTTP 对象放 dto，编排放 service，工具放 tool，数据读写放 repository |

## 固定入口与本地文件

`agent/` 下现有文件名、任务同步标记以及根目录的 Obsidian 入口保留；调整这些路径前需要核对外部工作台和 Vault 引用。这里不引入重复的 `.agent/`、`.agents/` 或多份工具专用规则。

`devmate.db` 是已有本地运行数据，保留原位置并由 Git 忽略。数据库默认相对于启动工作目录解析；本次不迁移数据库、不改数据源，避免切换到空库。`target/`、`node_modules/`、`dist/` 和 IDE 文件由忽略规则管理，无需为整理目录而删除。

历史交接中的 `docs/`、`DevMate-语雀/` 等路径只保留历史语义；当前产品资料统一使用 `文档/`。
