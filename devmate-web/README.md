# devmate-web：前端学习切片

当前页面接入本地项目管理 API：启动时读取后端健康状态和 SQLite 项目列表；可以登记本地项目目录、查看登记详情。M2 增加了手动触发的项目只读识别和本机 JDK/Maven/Git 版本扫描。Vite 把 `/api` 代理到 `http://127.0.0.1:8080`。

项目识别只读取用户选择的 Maven 配置；本机扫描只调用工具版本参数。Agent 对话可按需调用项目识别和本机环境扫描两个只读工具。偏好设置可配置 DeepSeek 模型与 API Key，并测试连接；密钥只保存在后端进程内存，重启后需重新输入。页面不构建或启动用户项目。

```powershell
npm install
npm run dev
```
